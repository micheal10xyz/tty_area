# UI_DESIGN：天通苑社区信息服务平台（便民黄页）

| 项目 | 内容 |
| -- | -- |
| 版本 | v0.1（MVP） |
| 平台 | 微信小程序（Skyline + glass-easel，750rpx 设计稿） |
| 关联文档 | docs/PRD.md、docs/USER_FLOW.md |

---

## 1. 设计目标

面向**全年龄段居民**（含中老年）的公益便民工具，优先保证：

- 看得清：字号大、对比足、点按目标 ≥ 88rpx
- 找得快：分类明确、常用热线直达、一键拨打零步骤
- 少出错：明确反馈、防误拨、关键操作二次确认
- 可信感：克制的绿色系 + 官方热线专区化视觉

## 2. 设计原则

简洁 > 装饰；信息密度低 > 高；每屏一个主任务；减少输入、减少点击、减少等待。

### 3.2 字体与字号（rpx）

| 用途 | 字号 | 行高 | 字重 |
| -- | -- | -- | -- |
| 页面大标题 | 40 | 56 | 600 |
| 导航栏标题 | 34 | 48 | 500 |
| 卡片标题 | 32 | 44 | 500 |
| 正文 | 28 | 42 | 400 |
| 辅助说明 | 24 | 36 | 400 |
| 标签/时间 | 22 | 32 | 400 |

### 3.3 间距 / 圆角 / 阴影

- 间距基准 4rpx 递增：8 / 16 / 24 / 32 / 48
- 页面左右安全边距 24rpx；卡片间距 16rpx
- 圆角：卡片 24、宫格块 20、搜索框 36（胶囊）、按钮全圆角、小标签 8
- 阴影：卡片轻投影 `0 4rpx 16rpx rgba(31,35,41,.06)`，仅用于浮层与卡片

### 3.4 图标

- 统一线性图标 2rpx 描边；分类宫格用「浅底圆角块 + 彩色线性图标」（推荐分类中性绿、热线蓝）
- 图标规格：宫格 96×96 容器、32rpx 图标；列表项 72×72 容器、36rpx 图标；tab 48rpx

## 4. 核心组件规范

### 4.1 自定义导航栏（复用 components/navigation-bar）

- 状态栏高度自适应 + 标题 34rpx 居中；首页可用大字标题风格，二级页标准居中标题
- 左返回箭头（非 tab 页）；背景随页面（首页白底，详情白底）

### 4.2 搜索框

- 胶囊形 72rpx，底 `#F2F3F5`，占位「搜服务，如：开锁」；带「搜索」icon

### 4.3 分类宫格（首页）

- 4 列宫格：容器 96×96 圆角 20 浅绿底 + 图标，下方名称 24rpx
- 「常用热线」宫格单独置顶分区，用蓝系浅底，**主操作是拨号**，点击直接进入热线路由列表

### 4.4 服务列表项卡片

```
┌────────────────────────────────┐
│ (图标) 名称               [热门]│
│        分类 · 组团 · 待复核标记 │
│        一句话描述(单行省略)     │
│        营业时间(选)            │
│                        [拨打电话] │ ← 次按钮样式
└────────────────────────────────┘
```

- 整卡可点进详情；右侧「拨打电话」次按钮避免误触卡片跳转
- 热门条目右上「热」橙色角标；超过 180 天未复核打灰色「待复核」标签

### 4.5 详情页（核心页）

```
┌────────────────────────────────┐
│ 名称 / 分组与组团 / 核实日期     │
│ 电话区（大字号 + 拨打次按钮）    │
│ ─ 信息卡：地址 / 营业时间 / 描述│
│ ─ 提示条：公益整理·自行核实      │
│ [纠错/申请下线]  [分享]          │
└────────────────────────────────┘
```

- 底部固定主按钮「拨打 xxx-xxxx」高 96rpx；拨打前弹确认窗（防误拨）
- 长按号码可复制

### 4.6 按钮体系

| 类型 | 样式 | 场景 |
| -- | -- | -- |
| 主按钮 | Brand 填充、白字、全圆角 88rpx | 拨打、提交 |
| 次按钮 | 白底 + Brand 描边 2rpx | 纠错、重试 |
| 文本按钮 | Brand 文字 | 查看详情、再试 |
| 警示文本 | 红 #FA5151 | 申请下线 |

- 禁用态：降透明度 40%；点击防抖；loading 态禁用

### 4.7 状态组件

- Loading：列表/详情用骨架屏（灰块脉冲），按钮 loading 用转圈
- Toast：顶/中轻提示，2s 自动消失
- Dialog：拨打确认、下线确认（蒙层 + 白卡 + 主/次按钮）
- Empty：插画占位 + 28rpx 文案 + 主/次按钮引导（收录）
- Error/Offline：断网插画 + 「加载失败」+ 重试按钮

## 5. 页面原型

### 5.1 首页 home（tab）

```
┌ 状态栏 ──────────────┐
│ 🏠 天通苑西二区便民     我的｜ ← 右上可进 profile（或tab）
├────────────────────┤
│ 🔍 搜服务，如：开锁      │
├────────────────────┤
│ ☎ 生活常用热线 (蓝底卡片) │
│ 物业 居委 派出所 供热      │
│ 供电 燃气 水务 急救?      │
├────────────────────┤
│ [便民服务] 全部          │
│ 维修 家政 开锁 搬家 │
│ 疏通 回收 快递 干洗 │
│ 配钥 宠物 ...       │
├────────────────────┤
│ 推荐服务              │
│ ▸ 卡1 卡2 (横向)        │
├────────────────────┤
│           ＋ 我要收录    │ ← 悬浮/底部入口
└────────────────────┘
```

- 状态：骨架屏；分类/推荐空态占位但**常用热线始终可见（缓存）**

### 5.2 分类/搜索列表 list

```
┌ 状态栏 返回 · 标题：管道疏通/搜索「开锁」 ┐
├────────────────────┤
│ [全部][常用热线][开锁][…]  ← 分类胶囊可横滑
├────────────────────┤
│ 卡片/卡片/卡片（分页加载） │
│ 空态：暂无收录 → 我要收录   │
└────────────────────┘
```

### 5.3 详情 detail

见 §4.5。字段缺失行隐藏；NotFound 态见 USER_FLOW E5。

### 5.4 提交 submit（收录/纠错共用）

```
┌ 返回 · 标题：收录建议 / 纠错 ┐
│ 类型选择（纠错时展示目标条目名） │
│ 名称* / 分类*（picker）         │
│ 电话* / 组团*（默认西二区）      │
│ 地址(选) 营业时间(选)           │
│ 描述 ≤200 字，实时计数           │
│ 纠错原因（纠错时必选 radio）     │
│      [提交]（校验+防抖）        │
└────────────────────┘
```

### 5.5 个人中心 profile（tab）

```
┌ 我的 ────────────┐
│ 我的提交 ＞        │
│ 意见反馈 ＞        │
│ 关于与公益声明 ＞   │
│ 隐私政策 / 用户协议 │
└──────────────────┘
```

### 5.6 我的提交 mine / 反馈 feedback / 关于 about

- mine：时间线式记录卡 + 状态徽标（待审核/已上线/已驳回/已处理/已下线）；空态引导
- feedback：radio 类型 + textarea + 联系方式(选) + 提交
- about：公益说明、免责声明、版本号、数据更新说明、联系运营方式

## 6. 交互细则

- 拨打按钮点击 → 确认 Dialog → `wx.makePhoneCall`；失败 toast + 支持长按复制
- 提交类按钮：防抖 + 提交中转 loading + 成功后 toast 并返回上一页（我的提交可见）
- 返回栈为空时（分享直达 detail/submit）提供兜底返回首页
- 列表滚动分页 onReachBottom，防重复请求；下拉刷新首页与列表
- 拨号计数、条目曝光等数据埋点：仅在首页/列表/详情执行，无第三方统计 SDK
